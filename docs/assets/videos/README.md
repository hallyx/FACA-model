# Simulation videos

Web copies of the source clips in the repository's `videos/` directory are stored here with matching filenames. Posters retain the original frame colors.

Run `python scripts/sync_site_videos.py` from the repository root after adding videos. The script updates `../site-config.js`. Its first video is featured, while other entries populate the compact gallery without duplication. Videos load on playback and retain their original proportions.

See `docs/website_zh.md` for complete configuration and publishing instructions.
